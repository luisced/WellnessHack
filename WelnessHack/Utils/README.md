# Utils

Utility functions and shared helpers.

## Directory Structure

### Helpers
Business logic helpers:
- `DateHelper.swift` - Date calculations and formatting
- `NumberFormatHelper.swift` - Percentage, score formatting
- `BodyBatteryCalculator.swift` - Energy score computation
- `NotificationScheduler.swift` - Scheduling notifications
- `ImageProcessor.swift` - Image compression and processing

### Extensions
Swift extensions:
- `DateExtensions.swift` - Date convenience methods
- `ViewExtensions.swift` - SwiftUI view modifiers
- `StringExtensions.swift` - String utilities
- `ArrayExtensions.swift` - Array helpers

### Constants
App-wide constants:
- `AppConfig.swift` - Feature flags and configuration
- `ErrorMessages.swift` - Localized error strings
- `AnalyticsEvents.swift` - Event names for tracking
- `APIEndpoints.swift` - Vapi and service URLs
