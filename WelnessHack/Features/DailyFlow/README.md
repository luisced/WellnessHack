# Daily Flow Feature

## 📋 Overview

Core daily experience covering morning briefing, interactive coaching, and energy tracking.

## 🎯 User Value

- Morning briefing with energy, calendar, and motivation
- Interactive voice/text coaching via ElevenLabs
- Real-time energy tracking
- Evening reflection

## 📱 Components

### Views
- `EnergyCoachView.swift` - Main coaching interface
- `EnergyDashboardView.swift` - Energy metrics dashboard
- `VoiceButtonView.swift` - Voice call trigger button

### ViewModels
- `EnergyCoachViewModel.swift` - Coaching logic and state management

## 🔗 Dependencies

- BodyBattery engine
- ElevenLabs Integration
- HealthKit service
- Calendar service
