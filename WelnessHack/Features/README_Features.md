# Features

Vertically sliced features representing distinct user journeys and value propositions in the AI Life Coach.

## Directory Structure

### Onboarding
Initial user setup flow covering:
- Permissions request (HealthKit, Calendar, ScreenTime, Camera, Notifications)
- Goal selection and persona setup
- Initial Body Battery calibration
- Vapi assistant introduction and first interaction

### DailyFlow
Core daily experience covering:
- Morning briefing generation (body battery, calendar, motivational message)
- Interactive Vapi chat for coaching, questions, and recommendations
- Real-time energy intervention prompts (breaks, meditations, quick actions)
- Evening reflection compilation and nightly narrative

### Nutrition
Food and health tracking covering:
- Photo capture and inference pipeline
- Nutrition analysis and feedback (macros, benefits, stability)
- Meal history logging and patterns
- Healthy alternatives and recommendations

### FocusGuardian
Work-life balance enforcement covering:
- Schedule-driven focus mode activation
- App blocking automation based on schedules
- Transition messaging (work to rest)
- Positive reinforcement and break reminders

### Reflections
Analytics and insight generation covering:
- Nightly reflection hub (daily metrics, charts, narrative)
- Weekly growth reports (habits, emotional trends, analytics)
- Monthly performance reviews (long-term patterns, triggers, strategies)

### Retention
Engagement and delight covering:
- Motivational nudges and milestone celebrations
- Contextual Easter eggs and surprise messages
- Pattern-based coaching prompts
- Streak tracking and achievement unlocks
