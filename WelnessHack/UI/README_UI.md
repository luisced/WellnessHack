# UI

SwiftUI views and components.

## Directory Structure

### Screens
Full-screen views for each feature:
- `OnboardingScreen.swift` - Initial setup flow
- `HomeScreen.swift` - Daily briefing and dashboard
- `VapiChatScreen.swift` - Voice/text conversation interface
- `NutritionScreen.swift` - Food tracking and analysis
- `FocusScreen.swift` - Focus mode and break management
- `ReflectionsScreen.swift` - Daily/weekly/monthly insights
- `SettingsScreen.swift` - User preferences and configuration

### Components
Reusable SwiftUI components:
- `BodyBatteryCircle.swift` - Circular energy meter
- `ChartView.swift` - Line/bar chart wrapper
- `VapiButton.swift` - Voice call trigger button
- `HabitCard.swift` - Habit display and toggle
- `MealCard.swift` - Meal entry display
- `DailyBriefingCard.swift` - Morning briefing layout
- `NotificationBanner.swift` - Toast/banner notifications

### Theme
Design system and styling:
- `Colors.swift` - Color palette
- `Typography.swift` - Font definitions
- `Spacing.swift` - Consistent spacing values
- `Modifiers.swift` - Custom view modifiers
