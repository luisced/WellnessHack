# Services

External system integrations and platform APIs.

## Directory Structure

### HealthKit
Apple HealthKit integration:
- Sleep data retrieval and caching
- HRV metrics extraction
- Activity and exercise data aggregation
- Permission requests and management
- Data sync and update listeners

### Calendar
Calendar and event management:
- Calendar.app / Notion API integration
- Event parsing and aggregation
- Schedule conflict detection
- Time block identification
- Workload analysis

### ScreenTime
Screen time and app focus integration:
- Focus Mode management
- App blocking and scheduling
- Screen time metrics
- Deep Focus vs. Light Focus modes
- Device lock and unlock events

### Camera
Photo capture and processing:
- Food photo capture
- Local photo library access
- Image metadata extraction
- Integration with nutrition inference pipeline

### Notifications
Push and local notifications:
- Local notification scheduling
- Push notification handling
- Deep linking to feature screens
- Notification preferences and opt-out management
