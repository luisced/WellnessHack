# Core

Foundational engines and integrations powering all features.

## Directory Structure

### BodyBattery
Energy scoring and aggregation system:
- Sleep data ingestion and analysis
- Heart Rate Variability (HRV) processing
- Activity and exercise tracking
- Composite energy score calculation (0-100 scale)
- Body battery trend analytics and prediction
- Visualization and charting data models

### GoalManagement
Goal and persona system:
- Goal taxonomy and selection flows
- User persona and identity tracking
- Goal progress monitoring
- Theater mental (visualization) narrative generation
- Weekly and monthly goal alignment checks

### VapiIntegration
Vapi voice/conversation orchestration:
- Vapi API client and configuration
- Call initiation and session management
- Message routing and context passing
- Vapi response handling and action triggers
- Error handling and fallback strategies
- Call history and transcript storage
